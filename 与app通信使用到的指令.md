# 幻彩灯灯带通信指令


## 广播头格式

**格式**：`zd + 设备分类 + 设备子分类 + 客户编号`


广播头改为：

```text
5A 44 00 02 01 E9 00 00  
```

---

## 指令前缀(所有指令都要附带)


```text
02 01 E9
```
 
---

## 指令格式

| 按高位从左到右排序：byte0 -> byte1 -> byte 2 |                |                                                                                  |
| ---------------------------------- | -------------- | -------------------------------------------------------------------------------- |
| byte 0                             | 0x7F           | 固定值，用于区分设备                                                                       |
| byte 1                             | 0xFF           | 固定值，用于区分设备                                                                       |
| byte 2                             | 模式索引值 mode_idx |                                                                                  |
| byte 3                             | 动画方向 anim_dir  | <br/>0x00：正向<br/>0x01：反向<br/>正向：从控制板连接灯带的一端开始，沿灯带的方向向另一端推进<br/>反向：从灯带另一端开始，沿相反方向 |
| byte 4                             | 动画速度           | 0 ~ 100，单位：百分比                                                                   |
| byte 5                             | 动画亮度           | 0 ~ 100，单位：百分比                                                                   |
| byte 6                             | 保留，未使用该功能      |                                                                                  |
| byte 7                             | 段数量(多少个灯为一组)   | 0x00：所有灯为同一组<br>0x01：一个灯为一组<br>0x02：两个灯为一组<br>超过了灯的数量：所有灯为同一组                    |
| byte 8                             | 底色，R分量         | 0x00 ~ 0xFF，默认为0x00                                                              |
| byte 9                             | 底色，G分量         | 0x00 ~ 0xFF，默认为0x00                                                              |
| byte 10                            | 底色，B分量         | 0x00 ~ 0xFF，默认为0x00                                                              |
| byte 11                            | 颜色数量           |                                                                                  |
| byte 12                            | 颜色 1，R分量       | 0x00 ~ 0xFF                                                                      |
| byte 13                            | 颜色 1，G分量       | 0x00 ~ 0xFF                                                                      |
| byte 14                            | 颜色 1，B分量       | 0x00 ~ 0xFF                                                                      |
| ...                                | ...            |                                                                                  |
| byte x - 2                         | 颜色 x，R分量       | 0x00 ~ 0xFF                                                                      |
| byte x - 1                         | 颜色 x，G分量       | 0x00 ~ 0xFF                                                                      |
| byte x                             | 颜色 x，B分量       | 0x00 ~ 0xFF                                                                      |

---

## 模式索引
  
| idx  | 名称    |
| ---- | ----- |
| 0x01 | 静态色   |
| 0x02 | 渐变    |
| 0x03 | 跳变    |
| 0x04 | 呼吸    |
| 0x05 | 流水    |
| 0x06 | 堆积    |
| 0x07 | 星空    |
| 0x08 | 星云    |
| 0x09 | 流星    |
| 0x0A | 流星雨   |
| 0x0B | 开幕/闭幕 |
| 0x0C | 跑动    |
| 0x0D | 跑动集合  |
